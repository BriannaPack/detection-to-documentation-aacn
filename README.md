# Detection to documentation: AACN Transform 2026 session site

Companion site for the AACN Transform 2026 podium presentation (Fri, Dec 4, 2026, Indianapolis) by Sharon K. Titus and Brianna M. Pack, Azusa Pacific University. It applies the SHOW approach across nursing courses and modalities. The OLC Accelerate 2026 version (online teaching across disciplines) lives at https://briannapack.github.io/detection-to-documentation/.

- Page text lives in `build.py`. Edit it, then run `python3 build.py` to regenerate `index.html` and `step-1/` to `step-3/`.
- Styles: `assets/site.css`. Videos: `assets/video/`. Slides: `downloads/` (replace the file, keep the name).
- Hosted on GitHub Pages from the `main` branch root.
