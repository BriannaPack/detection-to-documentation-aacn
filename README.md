# Detection to documentation: session site

Companion site for the AACN Transform 2026 podium presentation (Fri, Dec 4, 2026, Indianapolis) by Sharon K. Titus and Brianna M. Pack, Azusa Pacific University. Adapted from the OLC Accelerate 2026 site.

- Page text lives in `build.py`. Edit it, then run `python3 build.py` to regenerate `index.html` and `step-N/index.html`.
- Styles: `assets/site.css`. Videos: `assets/video/`. Handout and slides: `downloads/` (replace the file, keep the name, and the links keep working).
- Hosted on GitHub Pages from the `main` branch root.
